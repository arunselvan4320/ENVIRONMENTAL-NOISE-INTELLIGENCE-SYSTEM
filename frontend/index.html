The audio is processed in memory on this server and then discarded. It is not saved, and it is not sent to another service.

Connect a device

The ESP32 sketch in this project can send readings here. Register a sensor, copy its one-time token, then put that token in the sketch with your Wi-Fi name and the server address.

Where readings are sent
POST /api/observations · header X-Device-Token

Sending the same message twice is ignored. A bad token is rejected. Readings with a quality flag are left out of the forecast.
